# Выгрузка состояний ВПО в обеденное время

Динамическое приложение промышленной платформы: отчёт-матрица о состояниях
оборудования в окна обеденных перерывов + сводный показатель загрузки цеха.
Выгружается в Excel. Оборудование выбирается одним выпадающим деревом папок
(завод → отдел → цех → участок), период задаётся двумя датами (до 92 суток,
каждое окно показывается по суткам).

**Язык:** JavaScript (без сборки и зависимостей), CSS и HTML-разметка полей
вводных данных; страница и ресурсы описаны XML-манифестом пакета.

## Файл

`export.zip` — пакет для загрузки через «Импорт динамического приложения»:
`manifest.xml` (страница, 10 элементов, 4 события), вложенный `media.zip`
(код, стили, файл настроек, спиннер, документация) и CSS страницы.

## Данные

Состояния читаются из тегов состояний оборудования. Один и тот же запрос на
разных инсталляциях поддерживается по-разному, поэтому код перебирает четыре
способа получения интервалов (два калькулятора интервалов по тегам, перечень
интервалов тега и часовые корзины коннектора) и выбирает тот, который реально
отвечает данными; выбор и ответы всех запросов пишутся в консоль браузера.
Способ «часовые корзины» даёт точность до часа — такие строки помечаются в
отчёте знаком `*`.
Иерархия в дереве объекта берётся из папок организации: список всех папок с их
типами и цепочка родителей от папки станка. Если папки не отдают иерархию,
вместо дерева остаётся один список по участку.

## После загрузки

Настройки источника лежат в `manifest.json` (он же `4.tmp` внутри `media.zip`)
и перекрывают константы `manifest.js`: `appid` — экземпляр приложения с
оборудованием (пусто = брать из адреса страницы), `state_tag_names` /
`state_tag_oids` — соответствие тегов корзинам состояний (ОВП / Вкл. /
Неисправен / Выкл.), `use_sample_data` — демо-режим (по умолчанию `false`),
`debug` — вывод в консоль; `use_folder_tree` — дерево папок в выборе объекта,
`org_oid` — организация, чьи папки раскрывать. Окна перерывов задаются в
`LUNCH_WINDOWS` в
`manifest.js` и должны совпадать с подписями колонок таблицы.
Далее — создать экземпляр приложения и добавить в него станки.
