# Выгрузка состояний ВПО в обеденное время

Динамическое приложение для промышленной платформы: матрица состояний
оборудования в четырёх окнах обеденных перерывов, сводный показатель загрузки
цеха и выгрузка в Excel. Объект выбирается одним выпадающим деревом
(организация → завод → вид производства → цех → участок), период — двумя датами.

**Язык:** JavaScript без сборки и зависимостей, CSS, XML-манифест страницы.

`export.zip` — пакет для «Импорт динамического приложения»: `manifest.xml`,
вложенный `media.zip` (код, стили, настройки, документация) и CSS страницы.
Настройки источника — `manifest.json` внутри `media.zip`, история правок —
`fixlog.txt`.
